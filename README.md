# Крафт кликер

Веб-клиент idle-кликера. Пока есть только стартовое меню в духе Minecraft.

Бэкенд в этом репозитории не запускается — его делают отдельно.

## Как запустить

Нужны Git и Node.js.

```bash
git clone https://github.com/ClickerMasterPlay/Frontend.git
cd Frontend
git checkout dev
npm install
npm run dev
```

Открой в браузере адрес, который покажет Vite: обычно `http://127.0.0.1:5173/`.
